# ahead-feed-mohoyo-games

面向 Ahead / Open Event Feed 的长期运营游戏事件源集合。每款游戏使用独立 manifest，玩家可以只订阅自己关心的游戏。

| 游戏 | Manifest | 内容 |
| --- | --- | --- |
| 原神 | `feeds/genshin-impact.yaml` | 版本更新、版本前瞻、深境螺旋与幻想真境剧诗刷新 |
| 崩坏：星穹铁道 | `feeds/honkai-star-rail.yaml` | 版本更新、版本前瞻、混沌回忆/虚构叙事/末日幻影轮换 |

| 鸣潮 | `feeds/wuthering-waves.yaml` | 版本更新、版本前瞻、周年、联动与高难玩法节点 |

## 维护原则

- 重点记录玩家真正需要提前知道的“大事件”，不收录日常签到、普通卡池和零碎网页活动。
- 历史事件默认覆盖最近一年，并保留重要产品节点。
- 日期优先采用游戏官网、官方公告、官方直播等一手来源。
- 尚未公布确切日期的测试或版本使用 `unknown`，或使用 `likely` 明确标识尚待官方确认的排期，不把惯常周期伪装成正式档期。
- `confidence` 使用 `confirmed` / `likely` / `rumored` 表达信息强度。
- 中国大陆游戏优先按 UTC+8 表述；全球服事件保留官方发布时区。
- 每个事件尽量提供 `media` 图片。图片不在本仓库生成或重新托管，优先直接引用游戏官网、官方 CDN、官方社媒或经过验证的官方视频缩略图等远程来源。
- 外部图片版权归原权利人所有；本仓库仅保存 URL，不复制图片文件。远程素材失效时应替换为新的合规来源。

数据人工梳理，发现官方改期、图片失效或遗漏欢迎提交 Issue。
